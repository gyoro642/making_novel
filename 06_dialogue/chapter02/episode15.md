# 第15話 けろちん、張り切りすぎる セリフ

## タイトル
第15話 けろちん、張り切りすぎる

## 登場人物
けろちん、マクドナルドの店長、店員たち、実況の声（けろちんの頭の中）

## ナレーション・心情・セリフ
- ナレーション：翌日。けろちんがマクドナルドの前で拳を握る。
- セリフ：けろちん「今日は、昨日の倍頑張ろう！」
- セリフ：店員A「けろちん、これお願い。」
- セリフ：けろちん「はい！」
- セリフ：店員B「こっちも。」
- セリフ：けろちん「はい！」
- ナレーション：誰も頼んでいない仕事にも、手を挙げる。
- セリフ：けろちん「それ、僕やります！ あれも、僕やります！」
- 心情：けろちん（昨日褒められた。もっと頑張れば、もっと役に立てる！）
- ナレーション：店が混み始める。注文、ポテト、ドリンク。けろちんの頭の中で、どこからか実況の声が聞こえ始める。
- セリフ：実況の声「さあ始まりました、お昼のピーク！ けろちん選手、ポテトとドリンクを同時に抱えた！」
- セリフ：実況の声「おっと、ここでシェイクの注文！ 手が足りない！ カエルの手は二本しかない！」
- セリフ：けろちん「三本目、ください……！」
- セリフ：実況の声「けろちん選手、ポテトにシェイクをかけそうになった！ 危ない！ これは危ない！」
- セリフ：マクドナルドの店長「けろちん！ こっち、まだ終わってないよ！」
- セリフ：けろちん「すみません！」
- セリフ：実況の声「謝った！ 一回目！」
- セリフ：マクドナルドの店長「あっ、こっちも！」
- セリフ：けろちん「すみません！」
- セリフ：実況の声「二回目！ 止まらない！」
- セリフ：マクドナルドの店長「これ、違うよ！」
- セリフ：けろちん「すみません！！」
- セリフ：実況の声「三回目！ 本日の謝罪記録、更新です！」
- セリフ：マクドナルドの店長「……けろちん、倍頑張らなくていいから、一個ずつやろう。」
- セリフ：けろちん「すみません……倍、謝ってます……。」
- セリフ：実況の声「ここで試合終了〜。」
- ナレーション：けろちんは、どんどん小さくなっていく。
- ナレーション：仕事終わり。帰り道で涙目になる。
- セリフ：けろちん「昨日は褒められたのに……。……やっぱり、向いてないのかな。」
- ナレーション：振り返ると、店の明かり。昨日はあんなに明るく見えたのに、今日は遠い。
- セリフ：けろちん「辞めよう……。」
- セリフ：実況の声「けろちん選手、引退を表明しました。」
- セリフ：けろちん「……実況、まだいたんですか。」
- 心情：けろちん（昨日の倍、頑張ったのに。昨日の倍、遠くなっちゃった。）
