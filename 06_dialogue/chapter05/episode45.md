# 第45話 増えてきた！ セリフ

## タイトル
第45話 増えてきた！

## 登場人物
ぴょん吉、けろちん

## ナレーション・心情・セリフ
- ナレーション：ぴょん吉が働く。けろちんも働く。帰ってきて、貯金箱に入れる。ちゃりん。
- ナレーション：貯金箱の横に、けろちんが作った表。1万円ごとに、マスが一つ。
- セリフ：ぴょん吉「けろちん、1マスたまった。お祝いに、ラーメン行く？」
- セリフ：けろちん「行きません。それで減ります。」
- ナレーション：翌週。ちゃりん。2マス目。
- セリフ：ぴょん吉「2マス。ラーメン。」
- セリフ：けろちん「行きません。」
- ナレーション：その次の週。3マス目。
- セリフ：ぴょん吉「ラーメンの、小。」
- セリフ：けろちん「サイズの問題じゃないです。」
- ナレーション：ぴょん吉は、表の端に小さくラーメンの絵を描く。毎週、一杯ずつ増えていく。
- セリフ：けろちん「……ぴょん吉さん、ここ、ラーメンの表じゃないです。」
- セリフ：ぴょん吉「食べてない分。」
- セリフ：けろちん「食べてない分を、記録しないでください。」
- ナレーション：ある夜。けろちんが通帳を持って走ってくる。
- セリフ：けろちん「ぴょん吉さん！ 見てください！ こんなに貯まりました！」
- セリフ：ぴょん吉「おおー！」
- ナレーション：二匹で通帳を見つめる。数字が、前よりずっと増えている。
- セリフ：けろちん「本当に、お店できるかもしれませんね。」
- セリフ：ぴょん吉「できるよ。」
- セリフ：けろちん「まだ足りませんけど。……でも、近づいてます。」
- ナレーション：けろちんが、表の端のラーメンの絵を数える。一、二、三……十二杯。
- 心情：けろちん（ぴょん吉さん、十二回も、がまんしてたんだ。）
- セリフ：けろちん「……ぴょん吉さん。今日は、お祝いしましょうか。」
- セリフ：ぴょん吉「ラーメン！？」
- セリフ：けろちん「お店じゃなくて、家で作ります。袋のやつ。一袋を、二人で。」
- セリフ：ぴょん吉「半分こ？」
- セリフ：けろちん「半分こです。節約ですから。」
- ナレーション：台所に、湯気が立つ。小さな鍋に、一袋のラーメン。二匹で、はふはふ食べる。
- セリフ：ぴょん吉「……うまい。十二杯分、うまい。」
- セリフ：けろちん「一杯の半分ですけどね。」
- セリフ：ぴょん吉「でも、がまんした分、全部入ってる。」
- セリフ：けろちん「……それは、おいしそうですね。」
- ナレーション：次の日。袋のラーメンを買いに出た商店街で、ぴょん吉が掲示板の前に立ち止まる。
- ナレーション：大きな紙。「カエル祭り　開催者募集」。
- セリフ：けろちん「……ぴょん吉さん？ 目が、ラーメンの時と同じになってますよ。」
