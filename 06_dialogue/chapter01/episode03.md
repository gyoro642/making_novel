# 第3話 コンビニをやめる セリフ

## タイトル
第3話 コンビニをやめる

## 登場人物
ぴょん吉、コンビニ店長

## セリフ
- ぴょん吉「いらっしゃいませー！」
- ぴょん吉「袋、いりますか？」
- コンビニ店長「お願いします。」
- ぴょん吉「わかった！」
- ぴょん吉「おお、これ、色がきれい。」
- ぴょん吉「こっちの方が楽しそうだなぁ。」
- ぴょん吉「信号みたい。」
- 店長「ぴょん吉くん。」
- ぴょん吉「はい！」
- コンビニ店長「昨日言った、バックヤードの段ボール、片づけた？」
- ぴょん吉「段ボール。」
- コンビニ店長「うん、段ボール。」
- ぴょん吉「……ああ！」
- ぴょん吉「あったねぇ。」
- 店長「あったねぇ、じゃなくて。やってって言ったでしょ。」
- ぴょん吉「うん。」
- コンビニ店長「で、やった？」
- ぴょん吉「やってない。」
- 店長「じゃあ、今やってちょうだい。」
- ぴょん吉「わかった！」
- ぴょん吉「あ、これも並べた方がいいかも。」
- ぴょん吉「ぴょん吉くん。」
- コンビニ店長「はい！」
- ぴょん吉「段ボール。」
- コンビニ店長「あっ。」
- ぴょん吉「でもこれ、溶けないうちに並べた方がいいよ。」
- コンビニ店長「チョコは溶けない場所にあるから大丈夫。」
- ぴょん吉「そっか。」
- 店長「いいから、やってちょうだい。」
- ぴょん吉「いらっしゃいませー！」
- ぴょん吉「ぴょん吉くん。」
- 店長「はい！」
- ぴょん吉「段ボール。」
- コンビニ店長「あっ。」
- ぴょん吉「えっと。」
- けろちん「いい。レジは僕がやる。」
- ぴょん吉「ありがとう！」
- コンビニ店長「ありがとうじゃなくて。」
- 店長「ぴょん吉くん。」
- コンビニ店長「はい。」
- ぴょん吉「さっきから、言われたこと、ひとつも終わってないよ。」
- コンビニ店長「ひとつも？」
- ぴょん吉「ひとつも。」
- ぴょん吉「チョコは、ちょっと並んだよ。」
- コンビニ店長「それは頼んでない。」
- ぴょん吉「そっか。」
- ぴょん吉「ぴょん吉くん、聞いて。」
- コンビニ店長「聞いてるよ。」
- ぴょん吉「聞いてるだけじゃなくて、やって。」
- コンビニ店長「わかった！」
- ぴょん吉「その『わかった！』を、今日は三回聞いた。」
- コンビニ店長「三回も？」
- ぴょん吉「三回も。」
- 店長「もう、いいからやってちょうだい。ほんとに。今すぐ。」
- ぴょん吉「ぴょん吉くん？」
- 店長「あ、うん。」
- ぴょん吉「店長。」
- コンビニ店長「なに？」
- ぴょん吉「これ、どこに置くんだっけ。」
- 店長「昨日も言った。」
- ぴょん吉「昨日かぁ。」
- けろちん「今日はもういいよ。僕がやる。」
- ぴょん吉「いいの？」
- コンビニ店長「いいっていうか、今はその方が早い。」
- ぴょん吉「そっか。」
- ぴょん吉「なんか。」
- ぴょん吉「ん？」
- コンビニ店長「なんか、合わないな。」
- 店長「店長、力持ちだなぁ。」
- ぴょん吉「まあいいや。」
- ぴょん吉「次、何しようかな。」
