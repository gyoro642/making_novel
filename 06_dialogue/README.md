# 動画用台本

`04_manuscript/` の各話本文から、動画制作で使いやすいようにセリフ・心情・状況・動作を整理した派生フォルダです。

## 方針

- 正式な本文は `04_manuscript/` を正とする。
- このフォルダは動画制作向けの参照用とする。
- 本文を修正した場合は、対応するセリフファイルも更新する。
- 話者名は本文の前後関係から付ける。必要に応じて動画制作時に調整する。
- セリフだけで話が分かりにくい場合は、`## セリフ・心情・状況・動作`の中に短い心情・状況・動作を足して流れを補う。
- 心情はキャラクター本人の内面、状況は場面説明、動作は映像で見せる動きを書く。

## 各話フォーマット

```markdown
# 第X話 タイトル セリフ

## タイトル
第X話 タイトル

## 登場人物
登場人物一覧

## セリフ・心情・状況・動作
- 状況：場面説明
- 心情：本人が言葉にしていない感情
- 動作：映像で見せる動き
- セリフ：話者「セリフ」
```
