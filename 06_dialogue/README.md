# 動画用台本

`04_manuscript/` の各話本文から、動画制作で使いやすいようにナレーション・心情・セリフを整理した派生フォルダです。

## 方針

- 正式な本文は `04_manuscript/` を正とする。
- このフォルダは動画制作向けの参照用とする。
- 本文を修正した場合は、対応するセリフファイルも更新する。
- 話者名は本文の前後関係から付ける。必要に応じて動画制作時に調整する。
- セリフだけで話が分かりにくい場合は、`## ナレーション・心情・セリフ`の中に短いナレーションや心情を足して流れを補う。
- ナレーションは場面説明や映像で見せる動き、心情はぴょん吉またはけろちんが心の中で思っている内容、セリフは実際に声に出す言葉を書く。
- 心情には、読者向けの分析や「示される」などのメタ説明を書かない。

## 各話フォーマット

```markdown
# 第X話 タイトル セリフ

## タイトル
第X話 タイトル

## 登場人物
登場人物一覧

## ナレーション・心情・セリフ
- ナレーション：場面説明や映像で見せる動き
- 心情：ぴょん吉（心の中で思っていること）
- 心情：けろちん（心の中で思っていること）
- セリフ：話者「セリフ」
```
