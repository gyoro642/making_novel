# 第3章 二匹の出会い プロット

## 章の目的

正反対のぴょん吉とケロチンが出会い、一緒に暮らし始める。「違うからこそ支え合える」を示す。

## 開始時点

ぴょん吉は一人で気ままに暮らし、ケロチンは仕事の失敗を一人で抱えている。

## 終了時点

二匹は互いの違いを面白がり、一緒に暮らすことを選ぶ。

## 各話

| 話 | タイトル | 目的 | 状態 |
| --- | --- | --- | --- |
| 第21話 | 偶然の出会い | 雨の日の商店街で、落ち込むケロチンと雨を楽しむぴょん吉を出会わせる | 初稿作成済み |
| 第22話 | 一緒のタイミー | 同じタイミー先で、断れないケロチンとできないことは断るぴょん吉の違いを描く | 初稿作成済み |
| 第23話 | 一緒に帰る | 仕事帰りに一緒に食事をし、家が反対でも途中まで歩くぴょん吉の距離感を描く | 初稿作成済み |
| 第24話 | 一緒に暮らさない？ | ぴょん吉が軽く同居を提案し、ケロチンが戸惑いながらも一緒に暮らし始める | 初稿作成済み |
| 第25話 | 全然違う | 同居初日の朝と夜を通して、二匹の生活リズムの違いとぴょん吉の歌作りを描く | 初稿作成済み |
| 第26話 | ぴょん吉の歌 | ぴょん吉の歌がケロチンの心に触れ、二匹の距離が縮まる | 初稿作成済み |
| 第27話 | ウォーターサーバー | ケロチンが断れず契約した水を、ぴょん吉が喜んで飲むことで過去回を回収する | 初稿作成済み |
| 第28話 | 二匹で釣り | 釣れなくても楽しい時間を通して、結果だけではない楽しさを描く | 初稿作成済み |
| 第29話 | 公園の子どもたち | ケロチンが公園で子どもたちと遊び、世界が少し広がる | 初稿作成済み |
| 第30話 | 神社 | ケロチンが今の日々を大切に思い、第4章の居場所のテーマへつなぐ | 初稿作成済み |

## 伏線

二匹が安心して帰れる場所を求めていることを、第4章の夢につなげる。
