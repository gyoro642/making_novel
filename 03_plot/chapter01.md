# 第1章 プロット

## 章の目的

ぴょん吉の生き方と「失敗しても人生は終わらない」というテーマを示す。

## 開始時点

34歳のぴょん吉は、様々なアルバイトを転々としている。

## 終了時点

仕事をクビになっても自分の歩幅で進むぴょん吉の姿が、次章のケロチンとの対比として残る。

## 各話

| 話 | タイトル | 目的 | 状態 |
| --- | --- | --- | --- |
| 第1話 | はじめまして、ぴょん吉です | ぴょん吉の現在と口癖を示す | 未着手 |
| 第2話 | 働いて、クビになって | 仕事を失っても引きずらない姿を描く | 未着手 |
| 第3話 | 次のアルバイト | 様々な仕事を経験する | 未着手 |
| 第4話 | ぴょん吉の歩幅 | マイペースさが周囲とずれる | 未着手 |
| 第5話 | またクビになりました | 失敗しても人生は終わらないことを示す | 未着手 |
| 第6話 | なんとかなるさ | ぴょん吉の価値観を深める | 未着手 |
| 第7話 | 休むのも仕事 | 前へ進むために立ち止まる | 未着手 |
| 第8話 | 変わらない一日 | ぴょん吉の日常と孤独を描く | 未着手 |
| 第9話 | となりの気配 | ケロチン編への接続を作る | 未着手 |
| 第10話 | 明日もきっと | ぴょん吉編を締め、次章へつなぐ | 未着手 |

## 伏線

ぴょん吉の口癖「まぁ、なんとかなるさ。」を人物の核として扱う。
