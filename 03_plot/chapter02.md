# 第2章 プロット

## 章の目的

ケロチンの頑張りと傷つきやすさを描き、「頑張っているのに報われないこともある」というテーマを示す。

## 開始時点

ケロチンは一生懸命働いているが、失敗を自分の責任にし、人に利用されることで自信を失っている。

## 終了時点

ケロチンが一人で抱え込む状態のまま、ぴょん吉との出会いへ進む。

## 各話

| 話 | タイトル | 目的 | 状態 |
| --- | --- | --- | --- |
| 第11話 | ケロチンの朝 | 真面目な日常を示す | 未着手 |
| 第12話 | 一生懸命 | 働く姿と責任感を描く | 未着手 |
| 第13話 | 小さな失敗 | 失敗を過度に責める | 未着手 |
| 第14話 | 頼まれごと | 人に利用されやすい性格を示す | 未着手 |
| 第15話 | 報われない日 | 努力が結果につながらない | 未着手 |
| 第16話 | ごめんなさい | 自信を失っていく | 未着手 |
| 第17話 | 断れない | 自分より他人を優先する | 未着手 |
| 第18話 | 空回り | 頑張るほど苦しくなる | 未着手 |
| 第19話 | 帰り道 | ひとりで抱え込む限界を描く | 未着手 |
| 第20話 | 誰かと会う前夜 | 第3章の出会いへ接続する | 未着手 |

## 伏線

ケロチンが自分を責める癖と、居場所を求めていることを第3章・第4章へつなげる。
