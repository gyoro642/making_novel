# 第2章 プロット

## 章の目的

けろちんの頑張りと傷つきやすさを描き、「頑張っているのに報われないこともある」というテーマを示す。

## 開始時点

けろちんは一生懸命働いているが、失敗を自分の責任にし、人に利用されることで自信を失っている。

## 終了時点

けろちんが一人で抱え込む状態のまま、ぴょん吉との出会いへ進む。

| 話 | タイトル | 目的 | 状態 |

| 第11話 | 遅刻したけろちん | 遅刻を深く責めつつ、食べ物で少し抜けるけろちんを示す | 初稿作成済み |
| 第12話 | けろちん、褒められる | 褒められて急に張り切り、仕事を抱え込みすぎる | 初稿作成済み |
| 第13話 | 辞めたい | 断れずに失敗し、会社を辞める決意へ進む | 初稿作成済み |

| 第16話 | タイミーさん、けろちん | ぴょん吉と逆に「タイミーさん」を受け入れてしまう | 初稿作成済み |

## 伏線

けろちんが自分を責める癖と、居場所を求めていることを第3章・第4章へつなげる。
