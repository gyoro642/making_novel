# 第6章 夢が壊れる プロット

## 章の目的

開業資金を失う出来事を通じて、夢はお金ではなく諦めた時に終わると示す。

## 開始時点

二匹はようやく開業できるだけの資金を貯めている。

## 終了時点

けろちんは初めて自分から前を向き、二匹は再び貯金を始める。

## 各話

| 話 | タイトル | 目的 | 状態 |
| --- | --- | --- | --- |
| 第51話 | 開業資金 | 夢が目前にあることを示す | 未着手 |
| 第52話 | 予想外の出来事 | 資金を失うきっかけを置く | 未着手 |
| 第53話 | なくなったお金 | 開業資金を全て失う | 未着手 |
| 第54話 | やっぱり無理だった | けろちんが絶望する | 未着手 |
| 第55話 | 黙るぴょん吉 | ぴょん吉が初めて言葉を失う | 未着手 |
| 第56話 | 夢の終わり | 二匹が立ち止まる | 未着手 |
| 第57話 | また貯めればいい | ぴょん吉が夢を諦めない | 未着手 |
| 第58話 | 夢はなくなってない | けろちんが言葉を受け取る | 未着手 |
| 第59話 | 最初の一歩 | 二匹が再び貯金を始める | 未着手 |
| 第60話 | 諦めない朝 | 第7章へつなげる | 未着手 |

## 伏線

第57話の「夢はなくなってないもん。」を最終話の結末へつなげる。
