# 第6章 夢が壊れる プロット

## 章の目的

第5章で開業資金を大きく失った後の痛みと向き合い、夢はお金ではなく諦めた時に終わると示す。

## 開始時点

二匹はカエル祭りを成功させたが、開業資金をほとんど失っている。

## 終了時点

けろちんは初めて自分から前を向き、二匹は再び貯金を始める。

## 各話

| 話 | タイトル | 目的 | 状態 |
| --- | --- | --- | --- |
| 第51話 | たこ焼きパーティー | 資金喪失後の落ち込みの中、祭りの余り材料で日常を少し取り戻す | 初稿作成済み |
| 第52話 | 新メニューできた | 余り道具から新メニューが生まれ、ぴょん吉が次の祭りを考え始める | 初稿作成済み |
| 第53話 | まだ怖い | けろちんが再出発への不安を口にし、ぴょん吉の考え方に触れる | 初稿作成済み |
| 第54話 | 夢は残ってる | ぴょん吉がまだ店を作るつもりだと示し、けろちんがやめたくないと認める | 初稿作成済み |
| 第55話 | 町の声 | 商店街の人々の声から、祭りが二匹だけの失敗ではなかったと知る | 初稿作成済み |
| 第56話 | 小さく始めよう | けろちんが、お金を使わずできることから始めようと提案する | 初稿作成済み |
| 第57話 | もう一度、貯金箱 | 小さな貯金箱を用意し、二匹がもう一度貯金を始める | 初稿作成済み |
| 第58話 | 最初の一枚 | 祭りの写真を「ここから始まった」として喫茶店ノートに残す | 初稿作成済み |
| 第59話 | けろちんの提案 | けろちんが自分からコーヒーや料理の勉強を提案し、店を作りたいと言う | 初稿作成済み |
| 第60話 | 諦めない朝 | けろちんが自分からぴょん吉を起こし、第7章の再出発へ向かう | 初稿作成済み |

## 伏線

第5章第50話の「また貯めればいい」と、祭りの写真を再出発の支えとして第7章へつなげる。
